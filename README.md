# 🌟 Overview

**CineMood AI** is an intelligent **semantic mood-based movie recommendation system** that understands a user's emotional state through **natural language conversation** and provides **personalized, explainable movie recommendations**.

Unlike traditional recommendation systems where users manually select moods or genres, **CineMood AI infers emotional intent automatically** using **semantic understanding, conversational context, and emotional profiling**.

Think of it as:

> **Netflix × Conversational AI × Emotional Intelligence**

---

# ✨ Key Features

## 🧠 Semantic Mood Detection

Users do **not** manually select moods.

Instead of:

❌ *“Select Mood: Sad”*

Users simply type naturally:

```text
"College completely fried my brain.
Need something relaxing."
```

The system intelligently infers:

```text
Emotion: Mental Fatigue
Mood: Stress / Burnout
Intent: Relaxation
Energy Level: Low
```

---

## 💬 Conversational Recommendation Engine

CineMood AI behaves like an intelligent assistant.

Example:

**User**

```text
Honestly exhausted after exams.
```

**AI**

```text
Do you want something comforting
or something distracting?
```

The recommendation system continuously adapts using conversation context.

---

## 🎭 Emotion-Aware Recommendations

Recommendations are based on:

* Semantic Understanding
* Emotional Fit
* User Preferences
* Conversational Context
* Runtime Suitability
* Movie Popularity
* Ratings

---

## 🧠 Explainable AI

Instead of random suggestions, CineMood AI explains **why** each recommendation was made.

Example:

### 🎬 The Intern

⭐ 7.1

⏱ 121 min

🌐 English

📺 Netflix

### Why Recommended?

> You seem mentally exhausted and requested comforting but engaging content.
> This movie is emotionally warm, relaxing, and easy to watch.

# 🚀 Installation

Clone repository:

```bash
git clone https://github.com/VandanPatel18/CineMoodAI.git
```

Move into project:

```bash
cd CineMoodAI
```

Create virtual environment:

```bash
python -m venv venv
```

Activate environment:

### Windows

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

# ▶️ Run Project

```bash
python main.py
```

Or run Streamlit UI:

```bash
streamlit run ui/streamlit_app.py
```
